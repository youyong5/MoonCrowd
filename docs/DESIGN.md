# 设计、生态定位与创新边界

## 项目定位

MoonCrowd 是通用局部群体运动内核。输入是位置、速度、半径、期望速度、静态障碍与固定 dt；输出是新状态和可解释的速度约束。目标路线来自宿主规划器，画面来自宿主渲染器。

这种接口可以服务游戏、仿真、编辑器和算法实验。它不绑定单个场景，不依赖网页 DOM，也不将演示的路线策略固化进公共 API。

## 来源与独立工作

ORCA 约束、低维线性规划及回退来自 RVO2。`orca.mbt` 和 `lp.mbt` 是带有署名的移植代码，核心算法不主张原创。

MoonCrowd 的工程增量是：

1. **可组合的 MoonBit API**：结构化的圆盘配置、状态与错误，核心无第三方运行时依赖；不同渲染与应用消费相同结果。
2. **可观察的失败**：将每条约束、回退、残差和邻居截断返回给调用方，使实验与宿主降级策略有依据。
3. **原子固定步进**：所有个体共享旧态；输出校验失败时不污染半个世界。
4. **稳定生命周期与分支实验**：删除不复用 ID，内存检查点独立复制；适合比较策略和复现实验。
5. **精确重合的有限处理**：原版对应归一化可能除零；按稳定 ID 选择互为相反的方向，避免 NaN，并继续报告不可行残差。此处理不保证一次消除重叠。
6. **全场几何审计**：几何计数独立于避障邻居，补足局部约束残差的可观察性缺口；明细预算有界，精确计数不受截断影响。
7. **宿主集成**：原子批量期望速度和经过校验的配置更新，避免动态输入只应用一半。
8. **独立正确性证据**：固定上游提交生成预期值，四后端比较，而非让同一实现生成与验证自身答案。

这些是面向 MoonBit 的生态适配和工程设计增量，不宣称世界范围内首次提出上述机制，也不宣称比所有成熟引擎更快。

## 分层

| 层 | 文件 | 责任 |
| --- | --- | --- |
| 数值 | vector.mbt | 值向量、点线段距离、有限检查 |
| 约束与求解 | orca.mbt / lp.mbt | 移植核心 ORCA 与速度域求解 |
| 邻居查询 | neighbors.mbt | 自行实现的确定性包围盒树 |
| 世界 | types.mbt / simulator.mbt / updates.mbt | 校验、句柄、障碍拓扑、同步提交、检查点 |
| 几何审计 | audit.mbt | 独立全场净空、重叠计数与有界明细 |
| 宿主策略 | examples/scenes | 目标、到达、侧向偏好、门口途经点 |
| 展示 | examples/browser / web | MoonBit 适配、Canvas 绘制与界面 |

未来可将全局导航库的路径下一段转换为 preferred_velocity；也可和物理引擎协作，但物理引擎若更改速度，宿主必须同步状态并重新评估互惠模型的前提。

## 重复度检索与范围

2026-11-24 通过 GitHub、Mooncakes 与公开文档检索 `MoonBit ORCA`、`RVO language:MoonBit`、`crowd MoonBit`、`navmesh MoonBit` 等。结果中的同名 Orca 环境/设备项目不属于群体避障。

已知相邻能力包括 `moonbitstack/moongraph` 的图/网格搜索、`moonbitstack/moonmcl` 的运动规划、`Milky2018/moon_rapier` 的刚体物理；它们与“独立互惠局部速度选择”有不同职责。没有逐一审计其所有版本或私有实现，因此不写“生态绝无同类”或“唯一”。

本项目与 MoonDeform 的可变形物理也有不同职责。本版本没有实现刚体碰撞、软体约束、完整交通仿真或导航网格生成。
