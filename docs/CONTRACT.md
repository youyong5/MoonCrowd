# API 与数值契约

版本：0.1.0。坐标为 Cartesian Y-up；长度单位由调用方一致选择，速度为长度单位/秒。

## 输入范围

| 参数 | 范围 |
| --- | --- |
| 时间步 dt | `[1e-4, 1]` 秒，有限 |
| 位置、当前速度、期望速度的每个分量 | 有限、绝对值不超过 `1e6` |
| 圆盘半径 | `[1e-6, 1e4]` |
| 最大速度 | `[0, 1e4]` |
| 邻居距离 | `(0, 1e6]` |
| 最大邻居数 | 整数 `[0, 100000]` |
| 个体/障碍预测时间 | `[1e-4, 1e4]` 秒，且不小于 dt |
| 初始或外设当前速度 | 长度不超过 max_speed + `1e-9` |
| 活动个体 | 最多 10,000；生命周期最多 100,000 个稳定句柄 |
| 障碍 | 生命周期最多 4,096 个句柄；每个 2..1,024 个顶点 |
| 步数 | 最多 2,000,000,000 |

以上是拒绝非法输入的数值包络，不表示所有尺度组合都能稳定求解。实现保留 RVO2 的 `1e-5` 近似平行阈值；建议日常应用在半径 0.1..1、速度 0..5、典型场景尺度 1..100 内建模。极小特征、大尺度差异和严重重叠需要自行评估误差。

## 障碍语义

两个顶点表示双侧薄墙；三个及以上顶点表示简单实心多边形，输入方向会规范化为逆时针。允许简单凹多边形。不接受重复结束顶点、自交、反向折返、近零长度边、退化面积。独立障碍之间不可接触、相交、覆盖或嵌套；墙体拼接可用一个连续合法多边形描述。

几何相交检查含 `1e-10` 绝对容差。初态必须在实体外并保留圆盘半径净空。库不会把墙内个体投射出去，不进行接触求解或扫掠碰撞检测。

增删障碍更新下一步的约束，不表示障碍本身参与运动。移动障碍应由宿主重新建模，且宿主需避免把新障碍直接放到个体上。

## 更新与句柄

`step()` 从同一旧态读取所有个体，计算全部候选结果，校验有限性、速度上限和坐标范围后统一提交。校验失败抛出 `NumericalFailure`，本步不会部分提交。

不可行 LP 是可报告的求解结果，不等同于数值异常：回退的有限、速度有界结果仍可提交，调用方必须读取残差。

句柄只追加，不复用。删除后继续引用会抛出错误。`states()` 返回独立数组，状态与向量是不可变值；修改该数组不会更改世界。`Snapshot` 的存储字段私有；恢复时再次复制内部数组。

检查点只保存圆盘状态、障碍、固定时间步和计数，不保存宿主目标、输入记录或可视化轨迹。精确复现需要同版本、同后端、相同宿主输入序列。未提供跨进程序列化格式。

## 诊断定义

每条约束的可行侧为方向向量左侧：`det(direction, point - velocity) <= 0`。

- `max_violation`：所有已构造约束的最大正残差，单位为速度。
- `violating_agents`：残差大于 `1e-7` 的个体数；阈值是数值容差，不是安全裕量。
- `used_fallback`：初次二维 LP 未能满足所有约束，执行上游回退。
- `neighbors_truncated`：当前范围内找到的个体数超过 cap；cap 为 0 时不执行查询，显式关闭个体避障。
- `overlapping_neighbors`：求解前、被选中邻居中的重叠数量。不是全局碰撞统计，既不检查漏选个体，也不检查障碍穿透。
- `neighbor_candidates`：范围查询返回的个体数之和。不是内部树节点访问次数，也不是性能计时。

密集对冲、不同预测窗口、非互惠外部运动、邻居截断等会影响可行性。即使本步残差很小，也没有给出外部运动、未查询邻居或未来全部运动的保证。

## 复杂度与部署限制

邻居树采用逐层排序的包围盒划分；通常减少稀疏场景的距离查询，但构建不是严格线性。范围内结果先排序再截断；密集场景最坏仍可接近二次工作量。每个个体的静态障碍查询目前扫描所有边。

诊断会分配约束数组，未做零分配、并行化或 SIMD 性能承诺。10,000 个活动个体是输入容量边界，绝不是实测实时承载量。四后端已在 Linux 验证；Native 需要宿主 C 编译器，Windows/macOS 未单独验证。
