## 差分参考

原版 RVO2 固定到 `6b4eb00a93a9f3abf723235ff006d6aad3e2f212`，源码未修改，用 G++ 直接构建 oracle 驱动。

- Python 生成器种子：20261124。
- 24 组场景，每组 8 个体，逐步检查 12 步，共 2,304 条状态。
- 场景覆盖无障碍、双侧墙、凸多边形、凹多边形；参数包含不同半径、速度、预测时间和邻居截断。
- 每条状态比较位置 x/y、速度 x/y，共 9,216 个分量/后端。
- 上游 float 与 MoonBit Double 对照，绝对分量容差 `1e-4`。
- 不覆盖全部退化输入，不声称密集长时间轨迹与原版逐点相同。

输入和输出位于 `tests/fixtures/rvo2.json`；可运行生成器从固定上游重建。普通测试使用已提交的 MoonBit 数值样本，不需要 Python、G++ 或网络。

`generate_oracle.py --check` 严格核对固定场景与元数据，以 `1e-5` 绝对分量误差上限比较重新编译的 C++ 结果，再从保存的 JSON 重建格式化测试断言，逐字节核对 `oracle_wbtest.mbt`。库本身的差分测试容差仍为 `1e-4`。检查不覆盖原文件。

本地执行通过；5 项 Python 回归测试覆盖小幅尾差、超限差异、非有限/错误类型、缺失分量与输入/容差元数据修改。另在临时副本分别改动一个断言容差和一个 JSON 预期值，完整 CLI 检查均正确拒绝且不改变被改文件；此前的未跟踪上游源文件拒绝检查仍适用。

首次 GitHub Actions 的四后端任务全部通过，但字节级上游重生成检查因浮点尾差失败。修正后的 [完整 CI](https://github.com/youyong5/MoonCrowd/actions/runs/45413698402) 两项任务均已通过：四后端检查/构建/测试、CLI、独立消费者、网页构建和接口测试全部通过；参考核验的 9,216 个分量最大差异 `9.54e-7`，低于 `1e-5`，JSON 派生断言逐字节匹配。该记录对应提交 `a6c4254a1b3162178679f00f4a8e31143c790e4b`。

交付流程现在由 `tools/release.py` 统一执行检查、构建、测试与打包；仅接受干净 Git 源码目录和目录外的 ZIP 输出。归档仅使用已跟踪源码加明确列出的静态产物，附完整 Git bundle 与 SHA-256 文件清单；最终交付结果见归档中的相应源码提交。

## 400 步场景结果

48 个体、dt=0.05 秒，总仿真时长 20 秒。净空为所有圆盘两两中心距离减半径和的最小值，负值表示重叠。计数是跨步累计的“个体-步”，不是不同个体数量。

| 场景 | 到达数量 | 全程最小圆盘净空 | 回退个体-步 | 约束违反个体-步 | 实际重叠对-步 | 障碍穿透个体-步 |
| --- | --- | --- | --- | --- | --- | --- |
| 环形交换，演示侧向偏好系数 0.3 | 48/48 | 约 `+0.0000016653` | 0 | 0 | 0 | 0 |
| 交叉人流，同样提供侧向偏好 | 42/48 | 约 `-0.0000990737` | 1012 | 1010 | 16 | 0 |
| 双向狭窄通道，应用提供途经点 | 36/48 | 约 `-0.0526575550` | 3768 | 3765 | 1020 | 0 |

新增全场几何审计覆盖未查询/禁用的邻居、双侧墙、凸多边形内部、凹形缺口、容差、已删除句柄以及零明细预算下的精确计数；配置和批量更新覆盖失败原子性。

环形交换有严格回归断言：400 步始终分离、无残留约束违反、全部到达。另两个场景用于显示不可行/拥堵压力，未将它们描述为无碰撞成功案例。场景测试在这些状态下检查有限性、速度边界，并独立重算约束残差，与返回诊断对照。

开发过程中还用原版 RVO2 运行过相同密集环形压力设置，观察到重叠；这说明不能仅凭短程数值对照推断所有群体场景的碰撞保证。临时排查程序不作为公开 API 或正式基准。

## 2026-11-26：初审后开发与发布准备

已核验 [三作业 CI](https://github.com/youyong5/MoonCrowd/actions/runs/45775876884)，对应提交 `d7f0b155dcee0a1081ada8fc426b77f783cf1fa7`，四后端、固定上游参考、真实 Chromium 三个作业均成功。

- 核心库测试仍为四后端各 **61/61**，未将消费测试或比较分量重复计入。
- 独立消费覆盖公开运动与检查点恢复、重复 ID 批次拒绝的原子性、禁用邻居且零明细时的完整重叠统计。工作区与 `moon package` 实际 ZIP 两种来源，均为四后端各 **3/3**。
- 真实 Chromium 使用 Playwright 1.62.1。桌面为 1440×1000、DPR 1；手机为 390×844、DPR 3，并启用触摸。
- 桌面 HTTP、手机触摸 HTTP 和离线 `file://` 三种接入均通过：实际选中圆盘、键盘单步、播放/暂停、运行中重置、场景切换、数量变更、轨迹/速度开关、重置与求解失败的控件停用及恢复。
- 自动布局检查确认无页面横向溢出、画布像素尺寸匹配 DPR、画布包含可见个体像素，且没有页面异常、控制台错误或静态资源请求失败。报告和三张完整页面截图在该运行的 `mooncrowd-browser-report` 附件中。
- 修复了重置后沿用旧播放状态，以及数量变更失败后控件与实际场景不一致的问题。原 DOM stub 故障注入也加入这两条回归。
- 实际检查了上述桌面与手机截图；手机页头文字存在拥挤换行，已精简手机页头并加入来源链接单行布局检查，最终结果由后续提交 CI 验证。
