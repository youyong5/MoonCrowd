# MoonCrowd 0.1.0

首个 GitHub 版本交付可独立调用的 MoonBit 二维群体局部运动内核、原生命令行示例和可离线打开的静态演示。

## 核心能力

- 基于固定版 RVO2 移植的圆盘/静态障碍 ORCA 约束与低维线性规划。
- 自行实现的确定性邻居树、稳定句柄、输入与几何校验、同步原子步进。
- 原子期望速度批量更新、运行时配置校验和独立内存检查点。
- 约束残差、回退与邻居截断诊断，以及独立的全场几何审计、净空和有界重叠明细。

## 本轮补齐

- 独立消费者新增真实打包 ZIP 接入方式，覆盖公开运动、检查点、错误批次原子性和禁用避障后的审计行为；工作区与打包产物均为四后端各 3 项通过。
- 修复重置后继续播放，以及重置失败后数量控件与已提交场景不一致的问题。
- 新增真实 Chromium 的桌面、手机触摸/高 DPI 和离线文件测试；覆盖操作、画布、布局、错误恢复，CI 附测试报告与截图。
- 发布工作流要求同一提交的完整 CI 已成功，再重新校验和打包；已有版本标签不会被覆盖。

## 获取与复现

下载本页附件 `MoonCrowd-0.1.0.zip`，并可用同名 `.sha256` 文件核对完整性。ZIP 包含已跟踪源码、真实 MoonBit 编译的静态网页、Git 历史及内部 `MANIFEST.sha256`。解压后可打开 `MoonCrowd/web/index.html`；也可在干净 Git 源码目录执行：

```sh
python3 tools/release.py --output ../releases/MoonCrowd-0.1.0.zip
```

库测试已在 Linux 的 native、JavaScript、wasm-gc、wasm 四后端各 61/61 通过；24 组固定上游差分场景比较 2,304 条状态、9,216 个位置/速度分量，库测试绝对容差仍为 `1e-4`。参考生成核验器的数值上限为 `1e-5`，并严格核对 JSON 派生断言。

## 范围与发布状态

ORCA 与线性规划核心归属于上游，采用 Apache-2.0 并保留 NOTICE。局部速度选择不保证任意场景无碰撞、无拥堵或全部到达；本版没有全局寻路、接触力或连续碰撞检测。检查点只保存库状态，完整应用回放仍需宿主输入。

**GitHub Release 与 Mooncakes 是两种发布。此版本准备了 GitHub 源码/离线演示交付；Mooncakes 尚未发布，注册表安装验证尚未执行。** 具体发布步骤见 [PUBLISHING.md](https://github.com/youyong5/MoonCrowd/blob/main/docs/PUBLISHING.md)。Windows/macOS 和大规模实时性能尚未实测。
